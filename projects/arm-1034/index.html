三自由度机械臂取放动作

ROBOCON 赛场动作回放。

我担任电控组负责人，独立完成基于 STM32H723 与 FreeRTOS 的三自由度机械臂控制固件，构建 2 ms 主控制任务，并实现运动学、轨迹规划、运行状态机与取放任务链路。

实时控制与任务组织

  • 基于 STM32H723 与 FreeRTOS 构建 2 ms 主控制任务。
  • 实现关节限位、正逆运动学、雅可比解算、七次 S 曲线轨迹与重力前馈。
  • 使用 IDLE、READY、RUN、ESTOP 状态组织初始化、执行和安全保护。
  • 集成 FDCAN 电机控制、串口上位机命令、光电传感器与真空吸盘取放流程。

控制链路

控制固件通过 USART10 接收上位机启动和任务命令，检查设备在线与零位状态，再按状态机推进机械臂动作。程序经 FDCAN 发送电机与气泵控制命令，读取光电传感器输入，并执行关节限位、超速与力矩变化监控以及坐标禁区检查。
