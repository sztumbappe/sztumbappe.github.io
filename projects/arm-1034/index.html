ROBOCON 2026 · EMBEDDED ARM

R2 三自由度机械臂

面向竞赛取放任务的 STM32H723 控制固件，围绕实时任务、运动学、轨迹生成、电机通信与保护状态管理展开。

2025.09 — 2026.08FreeRTOS电控组负责人

项目仓库提供 STM32H723ZETx 与 FreeRTOS 固件、三自由度机械臂运动学模型、FDCAN 电机通信及上位机指令接口。个人职责为电控组负责人，主导机械臂控制固件与相关任务链路。

实时控制与任务组织

  • 基于 STM32H723 与 FreeRTOS 构建 2 ms 主控制任务。
  • 实现关节限位、正逆运动学、雅可比解算、七次 S 曲线轨迹与重力前馈。
  • 使用 IDLE、READY、RUN、ESTOP 状态组织初始化、执行和安全保护。
  • 集成 FDCAN 电机控制、串口上位机命令、光电传感器与真空吸盘取放流程。

控制链路

上位机通过 USART10 下发启动和任务命令；控制任务检查设备在线与零位状态，管理机械臂运动过程。电机与气泵分别通过 FDCAN 总线控制，光电传感器参与取放流程，安全监控处理超速、力矩变化和坐标禁区等条件。

仓库与技术资料

仓库 README 记录硬件连接、开发环境、运动学模型、上电流程、代码入口和标定指南，便于从功能层定位固件实现。
