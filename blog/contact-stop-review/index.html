四足运动控制方法论

从 MPC/WBC、强化学习到混合控制，按任务理解方法职责、工程前提与学习顺序。

更新于 2026-10-23项目详情 →

四足控制的学习主线，是弄清每一层根据什么信息、决定什么量、受到什么限制。本文以《四足机器人控制方法论与学习建议》为主要参考，围绕模型控制、强化学习和混合架构，整理我理解与选择方法时使用的框架。

文中的 MPC、WBC、适应与感知系统属于论文方法和后续学习参考；我的 Go2 训练实践另见四足强化学习训练技巧。阅读论文形成的方法认识，与已经实现并验证的项目能力分别说明。

1. 先按任务理解三条控制路线

方法的职责与主要前提
路线主要决策需要关注
MPC 与 WBC预测运动与脚力，协调当前全身执行模型、状态估计、接触约束与在线求解
强化学习根据观测生成关节目标或力矩等动作训练覆盖、观测接口与执行器一致性
模型规划与学习控制规划器给参考，学习控制器跟踪或修正参考的含义、更新周期与模块间误差

方法强弱需要放回任务判断：精确落脚关注几何与接触，复杂地形关注感知和恢复，高速运动关注执行器能力。不同机器人和评测条件之间，不能仅凭速度纪录或一段演示进行统一排名。

2. 模型路线：MPC 看未来，WBC 协调当前

典型链路是：IMU 与编码器 → 状态估计 → 步态与参考规划 → MPC → WBC → 关节反馈与驱动器。步态安排给出支撑与摆动时序；MPC 在预测区间内选择运动和接触力，只执行第一步，再根据新状态重算。Kim 等人的 Mini Cheetah 工作展示了 MPC 与全身冲量控制 WBIC 的分层组合。[1]

简化模型可以把身体近似为单刚体，利用脚力控制质心和机身转动。在接触安排固定、动力学对优化变量为线性、目标为凸二次型且约束为线性时，可以得到凸 QP。预测区间需要兼顾制动与换支撑需求、求解开销和模型偏差。

常见逆动力学 WBC 则在当前时刻协调全身加速度、接触力与关节力矩，满足浮动基座动力学：

M(q) q̈ + h(q,q̇) = Sᵀ τ + Jcᵀ λ

这里 M 是质量矩阵，h 包含重力与速度相关项，τ 是关节力矩，λ 是接触力，Jc 是接触雅可比，S 表示电机只直接驱动关节。理想固定接触还要求 Jc q̈ + J̇c q̇ = 0；摩擦、单边接触和力矩上限构成其他限制。具体 WBC 的任务层级与优化变量随实现而变，WBIC 不能代指所有 WBC。

使用触发点：关节单独跟踪正常，但机身姿态、支撑脚和力矩限制互相冲突时，学习 WBC 的协调作用；加减速或换支撑来不及时，检查 MPC 和步态参考是否提前考虑了未来支撑。

3. RL 路线：先查动作接口，再谈策略能力

一类常见四足 RL 架构读取关节状态、机身运动、速度命令和历史动作，输出默认姿态附近的关节位置目标，由 PD 环节产生力矩。Rudin 等人的并行训练工作结合 GPU 采样与地形课程，提供了理解这类训练流程的入口。[2]

qdes = qnominal + scale · action

τcmd = Kp (qdes − q) + Kd (vdes − q̇) + τff

这是用于理解接口的表达，具体系统可能没有前馈项，也可能输出速度、残差或直接力矩。仅凭输出维度等于关节数，无法判断命令模式。PPO 是训练算法，部署时运行的是策略推理；使用 RL 仍需要正确的坐标、传感器与下层反馈。

  • 观测：哪些量来自传感器、估计器或仿真真值？哪些只供 critic 训练，哪些会进入部署 actor？
  • 动作：关节顺序、零位、方向、缩放、限幅和 PD 参数怎样作用于实际关节目标？
  • 时间：物理步长、策略周期和动作保持时间分别是多少？改变降采样会改变闭环。
  • 任务：奖励、终止、重置、课程与随机化覆盖哪些条件？

使用触发点：需要在多种地形上连续跟踪速度并调整步态时，考虑 RL；出现零位错误、反馈延迟或驱动饱和时，先排查执行链。

4. 状态估计与历史适应解决不同问题

状态估计回答“身体现在如何运动”。IMU 提供角速度和比力，编码器与接触运动学约束身体运动。Bloesch 等人的工作把腿部运动学与 IMU 融合，并强调可观测性与滤波一致性；支撑脚打滑后，固定接触假设需要重新检查。[3]

历史适应回答“近期响应反映了什么外部或动力学条件”。RMA 使用基础策略与适应模块，根据近期状态和动作历史预测潜在环境特征，再调整动作。这里的在线适应主要是推断过程，并不意味着机器人行走时不断重新运行 PPO。[4]

DreamWaQ 将本体感知历史用于速度及潜在环境表示的学习，为有限传感条件下的运动控制提供另一种思路。隐含地形表示来自运动响应，不能直接解释为看到了前方尚未接触的沟或障碍。[5]

使用触发点：负载、摩擦或执行器状态变化后退化时，研究历史与适应；速度估计失真时，先核对接触、坐标与时间对齐，再比较估计方法。

5. 感知控制：让地形信息参与动作决策

本体感知反映已经发生的接触；相机、激光雷达和地图可以提供接触前的地形信息。Grandia 等人的感知非线性 MPC 将地形处理与运动优化结合，在模型规划中明确考虑可落脚区域和碰撞边界。地图中的可踩区域仍需面对状态误差与实际接触条件。[6]

Miki 等人的工作融合外部与本体感知，并处理外部感知不可靠的情况。值得学习的是如何在感知退化时维持控制，以及训练输入与部署输入怎样对应。[7]

地图只提供给 critic，与部署 actor 实际读取地图是两种配置。教师看到完整地形，也不能直接推出学生部署时拥有同样的信息。分析感知控制时，需要沿数据链确认：传感器看到了什么、地图何时更新、坐标如何对齐、哪一层使用了它。

使用触发点：踏石、连续间隙、禁止落脚区域等需要提前选择落脚位置的任务，适合比较感知规划与感知 RL。

6. 混合控制：明确学习模块补了什么缺口

DTC 用模型优化器提供运动与落脚参考，再训练神经网络跟踪器执行。规划器保留几何目标，学习跟踪器处理模型与接触偏差；这一组合需要清晰的参考接口，也仍依赖规划与感知。[8]

另一类组合在基线控制器上增加学习残差。读系统时要问：残差加在落脚、接触力、关节目标还是力矩上？幅度与更新周期是什么？如何处理饱和与模块失效？残差足够大时，原控制器的稳定性判断不能直接沿用。

运动先验与技能层级则把动作风格、底层技能和任务选择分开。它们适合复用已有动作，但仍需要验证数据覆盖和切换行为；自然的动作观感不能代替接触或能耗检查。

使用触发点：计划准确、实际接触偏差下却容易失稳时，考虑学习跟踪或残差；模块组合的价值要通过相同测试条件下的基线对照来判断。

7. 三条路线共同依赖的工程基础

  • 状态与接触：统一世界、机身和足端坐标，保留时间戳，检查支撑脚是否打滑。
  • 指令与执行器：核对关节顺序、零位、正方向、单位、命令模式、增益、力矩速度边界与反馈延迟。Hwangbo 等人的工作是理解执行器建模与仿真迁移的代表性入口。[9]
  • 多频率衔接：记录状态采样、规划求解、策略推理和驱动执行的周期，检查参考年龄、端到端时延与抖动。
  • 约束与停止：模型约束依赖模型和估计，奖励惩罚不能直接提供硬保证；驱动限制、指令超时和停止逻辑需要明确实现。
  • 迁移与验证：围绕实测的不确定性设计随机化；仿真、Sim2Sim 与真机分别提供不同层级的证据。

沿一次失败倒查时，我采用的分析顺序是：实际执行是否跟上命令 → 状态与接触是否可信 → 参考是否可实现 → 规划或策略是否选错动作。每一步都需要同步轨迹或接口记录支持。

8. 从具体问题选择下一步方法

工程选择入口，需结合硬件与任务验证
任务或症状优先研究先检查
固定站立、调高或倾斜身体接触力 QP / WBC运动学、接触与力矩接口
加减速、换支撑失稳MPC / 步态参考模型、预测区间与接触安排
常见地形速度跟踪本体感知 RL训练覆盖与执行器一致性
负载、摩擦变化后退化历史估计 / 适应时间对齐与估计误差
踏石、间隙、禁止落脚区感知规划 / 感知 RL地图精度与感知延迟
计划准确、接触偏差下失稳规划 + 学习跟踪参考接口与训练范围
仿真稳定、真机振荡执行链与模型排查零位、增益、饱和与时序

QP 是优化问题类别，OSQP 是求解器，MPC 是滚动预测控制方式，WBC 组织当前全身任务，RL 从数据中学习策略。读清这些层级，才能解释一个系统实际组合了哪些方法。

9. 结合我的控制背景安排学习顺序

结合已有的嵌入式、多电机通信、运动学与 Go2 训练实践，我按以下顺序补齐知识。下面是学习安排，每一步都对应一个可检查的成果。

  1. 读透策略执行链：把一帧观测、归一化、actor、动作缩放、PD 与饱和写成接口表，解释参数变化如何影响闭环。
  2. 补足式状态估计：在仿真中对比真值与估计，观察接触误判、打滑和时间错位带来的变化。
  3. 从脚力分配理解固定接触 WBC：找出动力学、接触等式、摩擦和力矩限制，读懂一次任务与 QP 的组装。
  4. 理解 MPC 增加的预测：比较只考虑当前与考虑未来多步的区别，明确预测状态、控制量和第一步输出。
  5. 按真实接口验证部署：依据实际 SDK 的权限与命令语义，分别检查状态、关节执行、时序与停止行为。

读论文时固定问六件事：控制对象是什么、运行时读取什么、输出什么命令、哪一层处理限制、方法依赖什么假设、实验证据在哪些条件下成立。C++ 学习也围绕闭环展开：状态快照、预分配、资源生命周期、求解器状态和时延记录都需要掌握。

这份方法论的落点：能沿完整闭环解释一个动作，指出限制来自哪一层，并用证据定位一次失败。实现路线由具体任务决定，能力表述以实际完成的接口、实验和部署验证为依据。

  1. Kim, D. 等（2019）. Highly Dynamic Quadruped Locomotion via Whole-Body Impulse Control and Model Predictive Control。阅读 MPC、WBIC 与关节控制的职责分工。

  5. Nahrendra, I. M. A., Yu, B. & Myung, H.（ICRA 2023）. DreamWaQ: Learning Robust Quadrupedal Locomotion With Implicit Terrain Imagination via Deep Reinforcement Learning。阅读本体感知历史与学习型估计。
